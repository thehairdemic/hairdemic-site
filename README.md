# Hairdemic Ecosystem

This repository deploys the current My Hairdemic ecosystem through Vercel.

The current application is served from `public/ecosystem.html` inside a minimal
Next.js shell. This is an intentional bridge deployment so the live product can
be tested at one stable URL while the UI is progressively refactored into native
Next.js routes/components.

## Deploy
Push to the repository connected to the Vercel project. Vercel will rebuild automatically.
